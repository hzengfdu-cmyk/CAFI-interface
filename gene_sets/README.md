# Gene sets

Invadopodia, CAFI interface, invadopodiahi malignant-cell and other functional gene sets are listed in Supplementary Table 6.

The public scripts expect a two-column long table at `data/gene_sets.tsv`:

```text
set_name    gene
Invadopodia ACTR2
Invadopodia ACTR3
```

Clinical information and patient-level data are not distributed with this repository.
